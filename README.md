# 模组说明

### 兼容性
* **验证版本**：Foundry VTT 13 + D&D 5.2.x
* **语言支持**：仅支持中文

---

### 模组简介
因为你不想让PL创建一大堆的宏给你造成文件管理上的麻烦，于是你提升了权限，禁用了宏。但在那之后，那个宏快捷菜单就像是一块无法愈合的疮疤，贴在每个PL的屏幕之上。安装这个MOD之后，这个疮疤将被修复，你的PL将拥有一块完整的下半边屏幕。

没人比我更懂控制欲超强的你，建议搭配[Alioth's Quickdraw Bar](https://github.com/Tony-Gan/alioths-quickdraw-bar)使用。
